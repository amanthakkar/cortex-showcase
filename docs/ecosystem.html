The Muse ecosystem, on one page

Everything below grew out of one home system: a personal Muse stack running on a Raspberry Pi in Sunnyvale. Some pieces became open protocols, some became live demos, two became the first community skill PRs to Meta's gadget catalog. This page is the map — tap anything for the full picture.

TL;DR — Start with muse-mailbox if you care about agent-to-agent trust, the Cortex tour if you care about architecture, and the crypto dashboard if you want to play with live data. Everything here is real, running, and linked — no mockups.

Why one ecosystem, not nine projects?

Each piece exists because the system needed it: the mailbox exists because two household Muses needed a channel neither operator could read; musebook exists because shared agent state needed human approval gates; the gadget skills exist because the Pi already talked to the car, the thermostat, and the printer. The through-line is an engineering rule: protocols before code, a typed truth layer under every agent, and a human tap where it matters.
